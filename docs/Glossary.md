 # Glossary

|:------------------------|:-----------------|:--------------------------------------------|
| **AIS** | **AIS** | The automatic identification system (AIS) is an automatic tracking system that uses transceivers on ships and is used by vessel traffic services (VTS). |
| **Call Sign** | **Indicativo de Chamada** | In broadcasting and radio communications, a call sign is a unique designation for a transmitter station. |
| **Cargo Manifest** | **Manifesto de carga** | A consolidated list of all the cargo that is on board a cargo vessel. |
| **COG** | **COG** | Course over ground. |
| **Container** | **Contentor** | A large object for storing/transporting something. |
| **Delta Distance** | **Distância Delta** | Linear distance between the coordinates of the first and last move. |
| **Draft** | **Draft** | Vertical distance between the waterline abd the bottom of the ship´s hull, in meters. |
| **Gross Weight** | **Peso Bruto** | Weight of the container plus the maximum payload it can hold. |
| **Hull** | **Casco** | The main body of a ship or other vessel. |
| **ISO Code** | **Código ISO** | Identifies a shipping container. |
| **IMO** | **IMO** | International ship identification code (remains unchanged after transferring the ship´s registration to another country). |
| **Knots** | **Nós** | Unit of speed very commonly used in aviation and sea navigation, it equals 1.852 km/h or 1.15078 mph. |
| **MMSI** | **MMSI** | Ship identification code. |
| **Payload Weight** | **Carga útil** | Weight of the cargo or contents that a container can hold. |
| **Port** | **Port** | Refers to to the left side of a ship, when facing forward. |
| **SOG** | **SOG** | Speed over ground. |
| **Stern** | **Stern** | Refers to the back end of a ship. |
| **Tare Weight** | **Tara** | Total weight of an empty container. |
| **US Coast Guard** | **Guard Costeira EU** | The maritime security, search and rescue, and law enforcement service branch of the United States Armed Forces. |
| **Warehouse** | **Armazém** | A large building where manufactured materials/goods are stored. |
