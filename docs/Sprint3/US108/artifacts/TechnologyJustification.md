#Technology Justification

**The database management system used in the project is RDB(MS) - Relational Database Management System.**

It is the most suitable for this project because:
*   It avoids data redundancy, which can have a negative impact on the quality of stored data,
    and can cause some anomalies in the insertion, update and elimination of data; This reduction
    in redundancy is achieved through Normalisation (the act of structuring a database in accordance
    with the 3 Normal Forms)
*   It is easier to use, comparing with other technologies;
*   Assures data security, since the data access is privileged, which means that the database
    administrator has the authority of giving access of data to other users.
